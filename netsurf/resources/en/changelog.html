JesusSaves Changelog

JesusSaves is a modified build of NetSurf 3.11. NetSurf is the work of the NetSurf Developers (see credits); the changes listed here were made by the JesusSaves project in 2026. JesusSaves is free software under the GNU General Public Licence version 2 (licence).

1.1.1 — November 2026

  • Scripture-aware address bar: type a reference such as John 3:16, 1 Cor 13:4-7 or Ps 23 and the passage opens (KJV on Bible Gateway). References are checked against the KJV, so ordinary searches are not hijacked.
  • Verse preview: hover a link whose text (or address) is a Bible reference and the King James text appears in the status bar. The whole KJV is built in and works offline.
  • Fixed: the Windows address bar never used web search, so typing plain words failed. It now searches DuckDuckGo; addresses still open directly.
  • Smaller, hardened Windows build: size-optimised, ASLR/DEP/high-entropy ASLR, stack protector and FORTIFY checks, stripped by default, reproducible timestamps.
  • Address-bar input is length-checked and trimmed.

1.1.0 — November 2026

  • Renamed to JesusSaves.
  • Search is DuckDuckGo only; hardened search-provider parser and URL builder (heap overflow fixed); plain words and verses such as “John 3:16” now search instead of being treated as host names.
  • Home page and default bookmarks replaced with Bible reference, evangelism, Baptist and sound-teaching sites, including christpath.org.
  • DNS locked to Cloudflare 1.1.1.3 / 1.0.0.3 (DNS-over-HTTPS fallback; fails closed; not user-changeable). An HTTP proxy resolves names itself and bypasses this.
  • Windows: statically linked 64-bit build; bounds-checked path handling, UTF-8 command line, file URL escaping, window-class checks, new installer.
  • User agent carries JesusSaves/1.1.0.

1.0.2 — November 2026

  • Renamed to JesusSaves everywhere users see it – window titles, About dialogs, messages, error pages, default bookmarks folder, desktop entry and Windows executable (JesusSaves.exe).
  • New JesusSaves logo, application icon, favicon and welcome-page banner.
  • About dialogs now show the JesusSaves version and compile date, credit the NetSurf Developers, and state that the modifications were made by the JesusSaves project.
  • New about:changelog page (this page), reachable from the About dialog and the Help menu. Help menu now opens the bundled pages (welcome, changelog, credits).
  • User agent string carries JesusSaves/1.0.2 next to the NetSurf/3.11 token for site compatibility.
  • Windows build keeps its profile in its own JesusSaves folder so it never mixes with a NetSurf install.

1.0.1 — November 2026

  • L1 New libnetsurf make target: the browser core as a static library, for Linux and Windows.
  • B1 Compiler versions such as 13-win32 no longer break the Makefile version test.
  • B2 Fallback inet_aton/inet_pton no longer clash with ws2_32 on Windows.
  • B3 Redundant fallback prototypes no longer fail the headless build on current glibc.
  • B4 Monkey front end: WINDOW EXEC/WINDOW CLICK returned after a bad-argument report instead of reading past argv.

1.0.0 — November 2026

Security and robustness audit of NetSurf 3.11 and its libraries.

  • R1–R9 RISC OS sprite decoder (librosprite) rewritten to validate every header field, bound every read and write, check every allocation and free everything on failure; a 12-byte image no longer aborts the browser.
  • F3 Disc-cache metadata is read with a bounded line reader instead of unbounded strlen.
  • F4 Disc-cache index: length overflow fixed, stale pointers cleared, leak fixed; a damaged index is now discarded and the browser starts with an empty cache instead of refusing to start.
  • F5 URL database: out-of-bounds write on an empty read and several leaks fixed.
  • F1 libnsfb X surface: use-after-free and connection leak fixed.
  • F2 content_destroy no longer dereferences NULL after a failed clone.
  • F6 GTK File > Open: NULL filename guarded and paths escaped, so names containing #, ? or % open correctly.
  • F7 GTK downloads: two leaks fixed.
  • F8 HTML tables: uninitialised struct member fixed.
  • F9 libwapcaplet test suite builds against current libcheck.
