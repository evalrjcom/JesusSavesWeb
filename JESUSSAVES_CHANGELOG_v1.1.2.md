# JesusSaves v1.1.2 — Changelog

JesusSaves is a modified build of NetSurf 3.11 (GPLv2). NetSurf is the work of the NetSurf Developers; changes are by the JesusSaves project.

## v1.1.2 (this release)
- Address-bar Bible references now open the **NKJV** on Bible Gateway (`version=NKJV`); the hover preview stays the built-in public-domain KJV (NKJV text is copyrighted and not embedded).
- Version bumped to 1.1.2 in version.c, useragent.c, Makefile.defaults, installer, scripts, CI and docs.

## v1.1.1
- **Scripture-aware address bar** (`desktop/scripture.c`, hooked in `search_web_omni`): "John 3:16", "1 Cor 13:4-7", "Ps 23", "Jude 3", "Song of Solomon 2:1" open the KJV passage on Bible Gateway. Book names/abbreviations are validated against the KJV chapter/verse table; ambiguous short words (is, am, ex, ti, ...) are not aliases. Option `scripture_urlbar` (default on).
- **Verse preview** (`html/interaction.c`): hovering a link whose text or URL holds a reference shows "John 14:6 (KJV): ..." in the status bar. Full 1769 KJV (31,102 verses, public domain) is embedded zlib-compressed (`scripture_kjv.c`, generated by `tools/gen_kjv.py`) and inflated lazily; freed at exit. Option `scripture_preview` (default on).
- **Fix:** Windows frontend never called `search_web_init()` and the address bar bypassed `search_web_omni()`; plain-word search from the address bar never worked. Both fixed; `search_url_bar` now defaults to on. Address-bar text is length-bounded (stack VLA) and trimmed.
- **Link flags:** `-Os -ffunction-sections -fdata-sections`, `--gc-sections`, `--dynamicbase --high-entropy-va --nxcompat`, `-fstack-protector-strong -D_FORTIFY_SOURCE=2 -lssp`, `--no-insert-timestamp`; `-g` removed; `NETSURF_STRIP_BINARY := YES` with a matching cross `strip`.
- Version bumped to 1.1.1 in version.c, Makefile.defaults, useragent.c, installer (VERSIONBUILD), make scripts and change markers; changelog renamed `JESUSSAVES_CHANGELOG_v1.1.1.md`.
- **NKJV by default (address bar):** typed references open `version=NKJV` on Bible Gateway; the hover preview stays the built-in public-domain KJV (the NKJV text is copyrighted and is not embedded).
- Tests: `tools/test_scripture.c` (parser, URL, KJV text, preview; ASan/UBSan clean); Wine check of hover preview and address bar.

## v1.1.0 baseline

## Branding
- Renamed to JesusSaves everywhere (code, resources, installer, UA string, logo). Version bumped to 1.1.0 in version.c, Makefile.defaults, useragent.c, make_logo.py, installer, file names.
- New logo (cross over wave) generated by `make_logo.py`.

## Search
- `resources/SearchEngines`: DuckDuckGo only (`https://html.duckduckgo.com/html/?q=%s`).
- `searchweb.c`: fixed heap overflow on templates with several `%s`; provider-file parser tolerant of CRLF/BOM/blank/comment lines, http(s)-only; blob ownership/leak fixes; built-in fallback; URL-bar heuristic so non-address text is searched.

## Home page and bookmarks
- `make_welcome.py` regenerates welcome pages (en, de, it, ja, nl, zh_CN): KJV John 14:6 / Acts 4:12, DuckDuckGo form, Bible, evangelism (Billy Graham, christpath.org), Baptist and sound-teaching links. No prosperity-gospel sites.
- Default hotlist rebuilt as a JesusSaves folder with four subfolders; empty-URL fallback is about:welcome.

## DNS
- `curl.c`: DNS pinned to 1.1.1.3, 1.0.0.3 via c-ares; DoH fallback; fail closed; no option/pref can change it.

## Windows
- Static x86_64 `JesusSaves.exe` (only Windows system DLLs imported); `libnetsurf.a` target.
- Audit fixes: path-buffer overflows (findfile.c), strdup/freopen/class-registration checks, UTF-8 argv, file-URL escaping, drive-letter bounds, filetype NULL guard.
- Installer: own install dir, shortcuts and uninstall key; 64-bit aware; stale NetSurf entries removed.

## Packaging
- 115 symlinks with a bogus path prefix repaired.
